## 1) meaning of probability

Probability measures how likely an event is to happen.

Examples:
- getting head on one coin toss
- getting a `6` on a die
- drawing a red card from a deck

## 2) outcomes and events

An outcome is one possible result.

For one coin toss:
- `H`
- `T`

An event is what we want to happen.

Example:
Event = getting head

Favourable outcomes are the outcomes that satisfy the event.

## 3) theoretical probability

If all outcomes are equally likely, then:

`Probability of an event = Number of favourable outcomes / Total number of outcomes`

### example 1: die
Probability of getting `4` on a die:

Favourable outcomes = `1`
Total outcomes = `6`

So probability = `1/6`

### example 2: coin
Probability of getting tail on one coin toss:

`1/2`

### example 3: cards
Probability of drawing a king from a standard deck of `52` cards:

Favourable outcomes = `4`

Probability = `4/52 = 1/13`

## 4) range of probability

Probability always lies between `0` and `1`.

- `0` means impossible event
- `1` means certain event

Example:
- probability of getting `8` on a normal die = `0`
- probability of getting a number less than `7` on a die = `1`

## 5) complement idea

If probability of an event is `P(E)`, then probability of not happening is:

`1 - P(E)`

This is useful when "not" type questions are easier than direct counting.

Example:
Probability of not getting a head on one coin toss:

`1 - 1/2 = 1/2`

## 6) exam-friendly summary notes

### must-know facts
- Probability is favourable outcomes divided by total outcomes.
- The formula works for equally likely outcomes.
- Probability is always between `0` and `1`.
- Impossible event has probability `0`.
- Certain event has probability `1`.

### one-line revision points
- count carefully
- favourable over total
- answer cannot be negative or above `1`

## 7) common mistakes students make

1. Forgetting that the sample space must contain all possible outcomes.
2. Counting favourable outcomes wrongly.
3. Giving a probability greater than `1`.
4. Using the formula when outcomes are not equally likely without checking.
5. Mixing up event and outcome.

## 8) board tips

- Write the sample space if the question is small.
- State favourable outcomes and total outcomes separately.
- Simplify the fraction at the end.
- Check whether the answer is between `0` and `1`.

## 9) how to remember the chapter

### memory box 1
Probability is a fraction of success cases out of all cases.

### memory box 2
No chance means `0`.

### memory box 3
Sure chance means `1`.

### memory box 4
If answer is bigger than `1`, something is wrong.

## 10) solved practice set

### question 1
Find the probability of getting an even number on one die.

Answer:
Even numbers are `2, 4, 6`

So probability = `3/6 = 1/2`

### question 2
Find the probability of getting a red card from a deck.

Answer:
There are `26` red cards in `52` cards.

Probability = `26/52 = 1/2`

### question 3
What is the probability of getting a number greater than `6` on a normal die?

Answer:
Impossible event, so probability = `0`
