# Probability chapter quiz

Answer these quick questions after revising the chapter notes.

## 1. Meaning

Probability measures:

1. certainty only
2. chance of an event
3. distance between events

Answer: 2
Explanation: Probability measures the chance that an event will happen.

## 2. Range

The probability of an event is always between:

1. `-1` and `1`
2. `0` and `1`
3. `1` and `10`

Answer: 2
Explanation: Probability values always lie between 0 and 1.

## 3. Certain event

A certain event has probability:

1. `0`
2. `1`
3. `1/2`

Answer: 2
Explanation: A certain event always happens, so its probability is 1.

## 4. Impossible event

An impossible event has probability:

1. `0`
2. `1`
3. `2`

Answer: 1
Explanation: An impossible event cannot happen, so its probability is 0.

## 5. Formula idea

Basic probability is:

1. favourable outcomes / total outcomes
2. total outcomes / favourable outcomes
3. favourable outcomes + total outcomes

Answer: 1
Explanation: Basic probability is favourable outcomes divided by total outcomes.
