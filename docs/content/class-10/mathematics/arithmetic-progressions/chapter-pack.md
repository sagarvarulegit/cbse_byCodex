# Arithmetic Progressions

## 1) what is an arithmetic progression

A sequence is called an arithmetic progression if the difference between consecutive terms is constant.

Examples:
- `2, 5, 8, 11, ...`
- `10, 7, 4, 1, ...`

Not an AP:
- `2, 4, 8, 16, ...` because differences are not equal

### important words
- first term = `a`
- common difference = `d`

For `2, 5, 8, 11, ...`
- `a = 2`
- `d = 3`

## 2) finding the common difference

Common difference:

`d = second term - first term`

or any next term minus previous term.

Example:
For `13, 10, 7, 4, ...`

`d = 10 - 13 = -3`

So AP can also decrease.

## 3) nth term of an AP

The nth term of an AP is:

`a_n = a + (n - 1)d`

### solved example
Find the 10th term of:
`3, 7, 11, 15, ...`

Here:
- `a = 3`
- `d = 4`

So:
`a_10 = 3 + 9(4) = 3 + 36 = 39`

### why this works
To reach the 10th term, we add the common difference `9` times.

## 4) finding a specific term

Example:
Find which term of the AP `5, 8, 11, ...` is `35`.

Use:

`a_n = a + (n - 1)d`

`35 = 5 + (n - 1)3`

`30 = 3(n - 1)`

`10 = n - 1`

`n = 11`

So `35` is the 11th term.

## 5) sum of the first n terms

The sum of the first `n` terms is:

`S_n = n/2 [2a + (n - 1)d]`

Another useful form:

`S_n = n/2 (first term + last term)`

### solved example
Find the sum of the first `20` terms of:
`3, 7, 11, 15, ...`

Here:
- `a = 3`
- `d = 4`
- `n = 20`

`S_20 = 20/2 [2(3) + 19(4)]`

`= 10 [6 + 76]`

`= 10 x 82`

`= 820`

## 6) applications of AP

AP is used when numbers increase or decrease regularly.

Common question types:
- savings growing by a fixed amount
- rows of seats increasing equally
- number patterns
- sum of odd numbers or multiples

### key habit
Before using a formula, identify:
- first term
- common difference
- number of terms

## 7) exam-friendly summary notes

### must-know facts
- An AP has a constant difference.
- nth term is `a + (n - 1)d`.
- Sum formula is `S_n = n/2 [2a + (n - 1)d]`.
- AP can increase or decrease.
- Negative common difference is allowed.

### one-line revision points
- AP means equal step size
- nth term gives position value
- sum formula adds many terms quickly

## 8) common mistakes students make

1. Checking only one pair of terms and declaring it an AP.
2. Writing `a + nd` instead of `a + (n - 1)d`.
3. Forgetting brackets in the sum formula.
4. Missing the negative sign when `d` is negative.
5. Using the sum formula when only one term is asked.

## 9) board tips

- Write `a`, `d`, and `n` before substituting.
- If the AP is decreasing, keep the sign of `d` carefully.
- In application questions, state what the final term or sum represents.
- For sums, simplify step by step instead of jumping.

## 10) how to remember the chapter

### memory box 1
AP means same jump every time.

### memory box 2
To reach the nth term, take `n - 1` jumps from the first term.

### memory box 3
Sum formula is just a fast way of adding a regular pattern.

## 11) solved practice set

### question 1
Is `4, 9, 14, 19, ...` an AP?

Answer:
Yes, because each difference is `5`.

### question 2
Find the 15th term of `2, 6, 10, 14, ...`

Answer:
`a = 2`, `d = 4`

`a_15 = 2 + 14(4) = 58`

### question 3
Find the sum of the first `10` terms of `1, 3, 5, 7, ...`

Answer:
`a = 1`, `d = 2`

`S_10 = 10/2 [2 + 9(2)] = 5(20) = 100`

   - a) `4`

   - c) `6`

   - a) `a + nd`
   - b) `a - nd`
   - c) `a + (n - 1)d`

   - a) positive `d`
   - b) negative `d`
   - c) zero `d`

   - a) `a_n`
   - b) `d_n`

   - a) `11`
   - b) `12`
   - c) `13`
   - d) `14`

2. c
3. b
4. c
