# Applications Blueprint

## Overview
Intermediate blueprint organizing the core deployable applications and platform services in the ChapterReady monorepo. This directory groups the primary web application portal, the Express backend API service, the operational admin dashboard, and the mobile application client specification.

## Subdirectories & Boundaries
- **web**: [Web Application](./web/README.md) - Next.js 14/15 web portal, student learning dashboard, interactive virtual labs, programmatic SEO question bank, and Android TWA shell.
- **api**: [Backend API Service](./api/README.md) - Express REST API service handling authentication, progress events, payments, RAG, and Tara AI tutor conversations.
- **admin**: [Admin Dashboard](./admin/README.md) - Next.js 14 administrative panel for operational reporting and pilot completion reviews.
- **mobile**: [Mobile Application](./mobile/README.md) - Flutter mobile client application specification for Android and iOS.
