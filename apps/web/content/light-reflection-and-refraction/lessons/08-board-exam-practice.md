# Board Exam Practice

## Recurring full-mark demand families

1. State both laws of reflection and draw the normal.
2. Define P, C, R, axis, F, f, aperture; use `R=2f`.
3. Complete any concave-mirror image table row.
4. Explain why convex mirrors are rear-view mirrors.
5. Select two valid standard rays and finish a mirror diagram.
6. Apply Cartesian signs before mirror calculation.
7. Use `m` sign to state image nature and `|m|` for size.
8. Derive missing `u`, `v`, `f`, `h'`, or `R` from mirror data.
9. Explain refraction using change of speed.
10. State both Snell laws; use `n=sin i/sin r`.
11. Explain glass-slab parallel emergence and lateral displacement.
12. Calculate `n=c/v` or relative index and compare optical density.
13. Define convex/concave lenses, O, F1/F2, and aperture.
14. Complete any convex-lens image-table row.
15. State the always virtual/erect/diminished concave-lens result.
16. Finish a lens ray diagram using two standard rays.
17. Apply lens sign convention and formula.
18. Explain why half a lens still forms a complete dimmer image.
19. Convert focal length and power with metre units.
20. Add powers of thin lenses in contact.
21. Use reversibility of light: reversing a prism ray retraces the same path, so
    the angle of deviation has the same magnitude.
22. Compare virtual images: a convex mirror always gives virtual, erect,
    diminished; a concave mirror gives virtual, erect, enlarged only for an
    object between P and F.
23. Find focal length from an equal-size real image: object and image at 2F.

## Five-mark numerical template

**Given -> sign convention -> formula -> substitution -> answer with unit ->
interpretation.**

Example: `u=-30 cm, f=+20 cm` for a convex lens:

`1/v - (-1/30)=1/20`, hence `1/v=1/60`, `v=+60 cm`;
`m=60/-30=-2`. The image is real, inverted, twice-sized, 60 cm on the other
side.

## Assertion/reason traps

- A real image can be caught on a screen; a virtual image cannot.
- Convex mirrors and concave lenses do not form real images of real objects.
- Optical density depends on light speed, not merely mass density.
- A ray at normal incidence does not bend, though its speed changes.
- A negative image height means inversion, not “negative size.”
- Scattering redirects light in many directions from particles; regular
  reflection sends light back from a surface according to `i=r`.

## Ray-diagram scoring checklist

Correct device shape and hatching; P/O, F, C/2F in order; object position;
two correct rays; arrowheads; dashed backward extensions only when virtual;
image arrow; nature, orientation, relative size, and position.
