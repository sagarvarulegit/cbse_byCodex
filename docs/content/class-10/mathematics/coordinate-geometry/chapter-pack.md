# Coordinate Geometry

This is an original teaching draft for Class 10 Mathematics, Chapter 7. The chapter becomes easier when students connect geometry to point positions on the plane.

By the end of this chapter, a student should be able to:
- locate points on the Cartesian plane
- use the distance formula
- use the section formula
- find the midpoint of a line segment
- find the area of a triangle using coordinates

## 1) Cartesian plane refresher

A point is written as `(x, y)`.

- `x` tells horizontal position
- `y` tells vertical position

The plane has four quadrants.

Example:
`(3, 2)` lies in the first quadrant.

## 2) distance formula

If the points are `(x1, y1)` and `(x2, y2)`, then distance is:

`d = sqrt((x2 - x1)^2 + (y2 - y1)^2)`

This comes from the Pythagoras theorem.

### solved example
Find the distance between `(2, 3)` and `(8, 11)`.

`d = sqrt((8 - 2)^2 + (11 - 3)^2)`

`= sqrt(6^2 + 8^2)`

`= sqrt(36 + 64)`

`= sqrt(100) = 10`

## 3) section formula

If point `P(x, y)` divides the line joining `A(x1, y1)` and `B(x2, y2)` internally in the ratio `m:n`, then:

`x = (mx2 + nx1)/(m + n)`

`y = (my2 + ny1)/(m + n)`

### meaning
The coordinates of the dividing point are weighted averages of the end points.

### warning
The ratio `m:n` means:
`AP:PB = m:n`

Students often reverse this.

## 4) midpoint formula

Midpoint is the special case where ratio is `1:1`.

So midpoint of `(x1, y1)` and `(x2, y2)` is:

`((x1 + x2)/2, (y1 + y2)/2)`

### example
Midpoint of `(4, 6)` and `(10, 2)` is:

`((4 + 10)/2, (6 + 2)/2) = (7, 4)`

## 5) area of a triangle

If the vertices are:
- `(x1, y1)`
- `(x2, y2)`
- `(x3, y3)`

then area is:

`1/2 [x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)]`

Take the absolute value if needed, because area cannot be negative.

### important use
If the area of a triangle is zero, the three points are collinear.

## 6) collinearity using area

Three points are collinear if they lie on the same straight line.

Using the coordinate formula:
- if area = `0`, points are collinear
- if area != `0`, points are not collinear

This is a common short-answer and proof-based application.

## 7) exam-friendly summary notes

### must-know facts
- Distance formula comes from Pythagoras theorem.
- Section formula gives coordinates of a dividing point.
- Midpoint formula is a special case of section formula.
- Area formula helps test collinearity.
- Area must be taken as positive finally.

### one-line revision points
- distance uses square root
- midpoint means average
- area zero means same line

## 8) common mistakes students make

1. Subtracting coordinates in the wrong order and then squaring wrongly.
2. Reversing the ratio in the section formula.
3. Forgetting that midpoint is just average of coordinates.
4. Leaving area negative.
5. Forgetting to divide by `2` in the area formula.

## 9) board tips

- Write the coordinate pairs clearly before substituting.
- Use brackets carefully when numbers are negative.
- In section-formula questions, state the ratio and the two end points first.
- In collinearity questions, write the area step fully and conclude with a sentence.

## 10) how to remember the chapter

### memory box 1
Distance formula is just Pythagoras on the graph.

### memory box 2
Midpoint means average of x-values and average of y-values.

### memory box 3
Area zero means the triangle has collapsed into a line.

## 11) solved practice set

### question 1
Find the distance between `(1, 1)` and `(4, 5)`.

Answer:
`d = sqrt((4 - 1)^2 + (5 - 1)^2)`
`= sqrt(9 + 16) = 5`

### question 2
Find the midpoint of `(2, -1)` and `(8, 7)`.

Answer:
`((2 + 8)/2, (-1 + 7)/2) = (5, 3)`

### question 3
What can you say if the area formed by three points is zero?

Answer:
The three points are collinear.
