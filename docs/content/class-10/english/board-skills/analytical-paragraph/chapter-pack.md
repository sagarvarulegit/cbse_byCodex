# Writing Skills - Analytical Paragraph

## chapter goal

Learn to write a 100-120 word analytical paragraph from a map, chart, graph, or cues.

## teacher note on textbook alignment

This pack supports the English writing-skill domain for analytical paragraphs using visual or cue-based input.

## chapter flow for the platform

1. Read the input.
2. Identify the main trend.
3. Compare key data.
4. Write one organised paragraph.
5. Check word limit and tone.

## 1) what analysis means

Analysis means explaining what the data or cues show.

Do not list every number. Select the most important trend, contrast, or pattern.

## 2) paragraph shape

Start with an overview sentence.

Then compare two or three important points.

End with a balanced conclusion based on the input.

## 3) language

Use words like increased, decreased, remained stable, highest, lowest, compared with, nearly, and about.

Avoid personal comments unless the prompt asks for opinion.

## 4) data honesty

Do not invent causes, predictions, or solutions.

Write only what the given data supports.

## exam-friendly summary notes

- Read title, labels, units, and time period.
- Write one paragraph, not a report with headings.
- Mention the main trend first.
- Compare key data points.
- Stay within the word limit.

## common mistakes students make

1. Listing all data without analysis.
2. Inventing reasons not shown in the input.
3. Using informal phrases like "a lot" without precision.

## board tips

- Plan three points before writing.
- Use comparison words.
- Keep the final sentence neutral and data-based.

## short answer practice

1. What is the first sentence of an analytical paragraph usually for?
2. Why should you avoid inventing causes?
3. Which words help with comparison?
4. Why are units important?

## mini quiz with answers

1. An analytical paragraph explains data or cues.
2. The main trend should appear early.
3. Comparison words improve clarity.
4. Unsupported causes should be avoided.
5. The word limit is part of the task.
