## 1) grouped data basics

In grouped data, values are arranged in class intervals with frequencies.

Example:
- `0-10`
- `10-20`
- `20-30`

The number of observations in each class is its frequency.

### class mark
Class mark is the midpoint of a class interval.

For `10-20`, class mark is:

`(10 + 20)/2 = 15`

## 2) mean of grouped data

The mean is the average.

For grouped data:

`Mean = (sum f_i x_i) / (sum f_i)`

where:
- `f_i` = frequency
- `x_i` = class mark

### step-deviation method
NCERT also uses assumed mean and step-deviation to make calculation easier.

Students should know the direct idea first and then the shortcut method.

## 3) median of grouped data

Median is the middle value.

For grouped data:

`Median = l + [(n/2 - cf) / f] x h`

where:
- `l` = lower boundary of median class
- `n` = total frequency
- `cf` = cumulative frequency before median class
- `f` = frequency of median class
- `h` = class size

### key step
First identify the median class using `n/2`.

## 4) mode of grouped data

Mode is the value with the highest frequency.

For grouped data:

`Mode = l + [(f1 - f0) / (2f1 - f0 - f2)] x h`

where:
- `l` = lower boundary of modal class
- `f1` = frequency of modal class
- `f0` = frequency before modal class
- `f2` = frequency after modal class
- `h` = class size

### key step
Modal class is the class interval with highest frequency.

## 5) cumulative frequency

Cumulative frequency means running total of frequencies.

It is especially useful for median questions.

### example idea
If frequencies are `3, 5, 7`, cumulative frequencies are:
`3, 8, 15`

This helps us locate where `n/2` lies.

## 6) exam-friendly summary notes

### must-know facts
- Mean uses class marks.
- Median needs cumulative frequency.
- Mode depends on the modal class.
- Median class is found using `n/2`.
- Correct table work matters more than speed.

### one-line revision points
- mean = weighted average
- median = middle class method
- mode = highest-frequency class

## 7) common mistakes students make

1. Using class interval end points instead of class marks for mean.
2. Forgetting to form cumulative frequency for median.
3. Choosing the wrong median class.
4. Mixing `f0`, `f1`, and `f2` in mode formula.
5. Using wrong class size `h`.

## 8) board tips

- Make a neat table before calculation.
- Show class marks and cumulative frequencies clearly.
- In median questions, write `n/2` separately.
- In mode questions, identify the modal class before substituting.

## 10) solved practice set

### question 1
What is the class mark of `20-30`?

Answer:
`(20 + 30)/2 = 25`

### question 2
Why is cumulative frequency useful?

Answer:
It helps identify the median class.

### question 3
What is the modal class?

Answer:
The class interval with the highest frequency.
