# Decimal expansion of rational numbers

This lesson helps students connect fractions and decimals. It is one of the easiest parts of the chapter once the rule becomes clear.

## start with a simple truth

A `rational number` can have:
- a `terminating decimal`
- or a `repeating decimal`

It will never become a non-repeating endless decimal. That kind of decimal is irrational.

## examples first

### `terminating decimal`
`13/40 = 0.325`

### another `terminating decimal`
`29/125 = 0.232`

### non-terminating `repeating decimal`
`7/12 = 0.58333...`

## the main rule

First, write the fraction in `lowest form`.
Then look only at the denominator.

- if the denominator has only `prime factors` `2` and/or `5`, the decimal terminates
- if the denominator has any `prime factor` other than `2` or `5`, the decimal repeats

## why `2` and `5` matter

Our decimal system is based on `10`.
And:

`10 = 2 × 5`

So denominators built from `2` and `5` fit nicely into decimal form.

## do not skip `lowest form`

This is very important.
Always reduce the fraction first.

Example:
`6/15`

If you look directly at denominator `15`, you may get confused.
First reduce:

`6/15 = 2/5`

Now denominator is only `5`.
So the decimal terminates.
In fact,
`2/5 = 0.4`

## solved example 1
Check whether `13/40` terminates.

Factorise the denominator:
`40 = 2³ × 5`

Only `2` and `5` are present.
So the decimal terminates.

Answer:
`13/40 = 0.325`

## solved example 2
Check whether `7/12` terminates.

Factorise the denominator:
`12 = 2² × 3`

A `prime factor` `3` is present.
So the decimal does not terminate.
It repeats.

Answer:
`7/12 = 0.58333...`

## solved example 3
Check whether `11/24` terminates.

Factorise the denominator:
`24 = 2³ × 3`

Since `3` is present, the decimal will not terminate.
It will repeat.

## solved example 4
Check whether `9/20` terminates.

Factorise denominator:
`20 = 2² × 5`

Only `2` and `5` are present.
So the decimal terminates.

In fact,
`9/20 = 0.45`

## common mistakes

1. Not reducing the fraction to `lowest form`
2. Looking at the numerator instead of the denominator
3. Forgetting that only `2` and `5` allow `terminating decimals`
4. Thinking a `repeating decimal` is irrational
5. Saying “non-terminating” without checking whether it repeats

## memory trick

`2` and `5` are friends of base `10`.

## board tip

If the question asks about decimal type, do not start long division first.
`Prime factorise` the denominator. That is cleaner and faster.

## compare these four cases

- `3/8`: denominator `8 = 2³`, so terminating
- `7/25`: denominator `25 = 5²`, so terminating
- `5/6`: denominator `6 = 2 × 3`, so repeating
- `11/15`: denominator `15 = 3 × 5`, so repeating

## quick practice

1. Does `3/8` terminate or repeat?
2. Does `7/25` terminate or repeat?
3. Does `5/6` terminate or repeat?
4. Does `14/35` terminate or repeat after reducing to `lowest form`?

## answer check

1. `3/8` terminates because `8 = 2³`
2. `7/25` terminates because `25 = 5²`
3. `5/6` repeats because `6 = 2 × 3`
4. `14/35 = 2/5`, so it terminates

## one-minute revision

- first reduce the fraction to `lowest form`
- then `factorise` the denominator
- only `2` and `5` mean `terminating decimal`
- any other `prime factor` means `repeating decimal`

## comic recap

- Denominator: “Please check me first. I am the main character here.”
- `2` and `5`: “We are decimal-friendly friends.”
- `3`: “If I enter the denominator, the decimal keeps repeating.”
- Student: “So first reduce, then check denominator. Got it.”

## remember this line

If the denominator has only `2` and `5`, the decimal ends. If not, it repeats.
