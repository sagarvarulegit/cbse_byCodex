## NCERT Chapter 4 — Quadratic Equations Content

### Key Concepts to Cover:

**1. What is a Quadratic Equation?**
- Standard form: ax² + bx + c = 0 (a ≠ 0)
- Degree 2 polynomial equation
- Examples: x² - 5x + 6 = 0, 2x² + 3x - 5 = 0

**2. Solving Methods:**
- **Factorisation** — splitting the middle term
  - Example: x² - 5x + 6 = 0 → (x-2)(x-3) = 0 → x = 2 or x = 3
- **Completing the Square** — converting to (x + a)² = b form
  - Example: x² + 6x + 5 = 0 → (x+3)² = 4 → x = -1 or x = -5
- **Quadratic Formula** — x = (-b ± √(b²-4ac)) / 2a
  - Works for ANY quadratic equation

**3. Nature of Roots (Discriminant)**
- D = b² - 4ac
- D > 0 → Two distinct real roots
- D = 0 → Two equal real roots (one repeated root)
- D < 0 → No real roots (two complex roots)

**4. Sum and Product of Roots**
- If roots are α and β:
  - Sum: α + β = -b/a
  - Product: α × β = c/a

**5. Forming Quadratic Equations from Roots**
- x² - (sum of roots)x + (product of roots) = 0
- x² - (α+β)x + αβ = 0

### Tips & Tricks to Include:
1. **Quadratic Formula memory aid**: "x equals minus b, plus or minus root b squared minus 4ac, all over 2a" — sing it like a song
2. **Discriminant shortcut**: Just check b² - 4ac sign. Positive = 2 roots, Zero = 1 root, Negative = no real roots
3. **Factorisation trick**: Find two numbers that MULTIPLY to give ac and ADD to give b
4. **Completing the square**: Half of b, square it, add to both sides
5. **Sum/product shortcut**: α+β = -b/a, αβ = c/a — no need to find actual roots
6. **Common mistakes**: Forgetting a≠0, sign errors in quadratic formula, wrong discriminant calculation
7. **Real-world connection**: Projectile motion, area problems, speed/distance problems use quadratic equations
