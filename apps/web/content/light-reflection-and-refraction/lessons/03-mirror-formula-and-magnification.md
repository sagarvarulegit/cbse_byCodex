# 9.2.3 New Cartesian Sign Convention

- object is placed to the left; incident light travels left to right;
- measure all axial distances from pole P;
- right of P is positive, left is negative;
- height above axis is positive, below is negative.

Therefore:

- real object: `u < 0`;
- concave mirror: `f < 0`, `R < 0`;
- convex mirror: `f > 0`, `R > 0`;
- real inverted image in front: `v < 0`, `h' < 0`;
- virtual erect image behind: `v > 0`, `h' > 0`.

# 9.2.4 Formulae

`1/f = 1/v + 1/u`

`m = h'/h = -v/u`

- `m < 0`: real, inverted;
- `m > 0`: virtual, erect;
- `|m| > 1` enlarged, `|m| = 1` same size, `|m| < 1` diminished.

## Safe numerical method

1. draw a rough diagram;
2. list signed `u, f, h`;
3. substitute into the formula before rearranging;
4. retain units;
5. interpret signs and size.

## Worked examples

### Convex mirror: `u=-10 cm`, `f=+15 cm`

`1/v - 1/10 = 1/15`, so `v = +6 cm`.

The image is behind the mirror, virtual, erect, and diminished.

### Concave mirror: `u=-27 cm`, `f=-18 cm`, `h=7 cm`

`v=-54 cm`; `m=-v/u=-2`; `h'=-14 cm`.

Place the screen 54 cm in front. Image is real, inverted, and twice-sized.

## Common mistakes

- Mirror formula has a **plus** between `1/v` and `1/u`.
- Do not discard the calculated sign.
- Magnification for a mirror contains `-v/u`.
