# Circles

This is an original teaching draft for Class 10 Mathematics, Chapter 10. The chapter is short, but the theorem statements must be remembered with exact meaning.

## chapter goal

By the end of this chapter, a student should be able to:
- understand the meaning of a tangent to a circle
- use the theorem that radius to the point of contact is perpendicular to the tangent
- use the converse idea in figure-based questions
- prove that tangents from an external point are equal
- solve standard board-style tangent questions

## 1) tangent and point of contact

A tangent to a circle is a line that touches the circle at exactly one point.

That point is called the point of contact.

### compare with secant
A secant cuts the circle at two points.
A tangent touches it at one point.

## 2) number of tangents from a point

- A point inside the circle: no tangent can be drawn
- A point on the circle: exactly one tangent
- A point outside the circle: exactly two tangents

This is a very common concept question.

## 3) radius perpendicular to tangent

The tangent at any point of a circle is perpendicular to the radius through the point of contact.

If `PT` is a tangent at point `P` and `OP` is the radius, then:

`OP perpendicular PT`

### meaning in plain words
The radius stands straight on the tangent.

## 4) tangents from an external point

If two tangents are drawn from an external point to a circle, then their lengths are equal.

If `PA` and `PB` are tangents from external point `P`, then:

`PA = PB`

### why this matters
This theorem helps in:
- finding unknown lengths
- proving symmetry in figures

### solved example
If one tangent from point `P` has length `8 cm`, the other tangent from the same point also has length `8 cm`.

## 5) exam-friendly summary notes

### must-know facts
- Tangent touches the circle at one point.
- Radius to the point of contact is perpendicular to the tangent.
- From an external point, two tangents can be drawn.
- Tangent lengths from the same external point are equal.

### one-line revision points
- one touch only
- radius and tangent make `90 deg`
- outside point gives equal tangents

## 6) common mistakes students make

1. Mixing tangent and secant.
2. Forgetting that perpendicularity happens at the point of contact.
3. Saying every outside point gives one tangent instead of two.
4. Using the equal-tangents theorem for tangents from different external points.

## 7) board tips

- Mark the point of contact clearly in the figure.
- Write theorem statements fully before using them in proofs.
- If lengths are asked, first identify which segments are tangents from the same external point.

## 8) how to remember the chapter

### memory box 1
Tangent means single touch.

### memory box 2
Radius at touch point stands at right angle.

### memory box 3
Two tangents from one outside point are twins in length.

## 9) solved practice set

### question 1
How many tangents can be drawn from a point on the circle?

Answer:
Exactly one.

### question 2
If `PA` and `PB` are tangents from point `P`, and `PA = 6 cm`, find `PB`.

Answer:
`PB = 6 cm`

### question 3
What angle does the radius make with the tangent at the point of contact?

Answer:
`90 deg`

## 11) mini quiz with answers

### quiz
1. A tangent touches the circle at:
   - a) two points
   - b) one point
   - c) three points
   - d) no point

2. Radius at the point of contact is:
   - a) parallel to tangent
   - b) equal to tangent
   - c) perpendicular to tangent
   - d) outside the circle

3. From an external point, number of tangents is:
   - a) `0`
   - b) `1`
   - c) `2`
   - d) `3`

4. If `PA` and `PB` are tangents from `P`, then:
   - a) `PA > PB`
   - b) `PA < PB`
   - c) `PA = PB`
   - d) no relation

5. A line cutting the circle at two points is:
   - a) tangent
   - b) secant
   - c) radius
   - d) chord only

### answer key
1. b
2. c
3. c
4. c
5. b
