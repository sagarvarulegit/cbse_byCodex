# Quadratic Equations

> 2026-27 curriculum scope: factorisation, the quadratic formula, the discriminant and situational problems are board-exam topics. Completing the square remains a support method and must not be counted as board coverage.

This is an original teaching draft for Class 10 Mathematics, Chapter 4. The purpose is to make quadratic equations feel like a set of clean methods, not a chapter of memorised tricks.

## chapter goal

By the end of this chapter, a student should be able to:
- identify a quadratic equation in standard form
- solve quadratic equations by factorisation
- recognise completing the square as a support method outside current board scope
- use the quadratic formula correctly
- choose the suitable method in a board question

## 1) what is a quadratic equation

A quadratic equation in one variable is an equation of the form:

`ax^2 + bx + c = 0`

where `a != 0`

Examples:
- `x^2 - 5x + 6 = 0`
- `2x^2 + 7x - 4 = 0`

Not quadratic:
- `3x + 2 = 0`
- `x^3 - 1 = 0`

## 2) standard form and roots

The values of `x` that satisfy the quadratic equation are called its roots.

For example:

`x^2 - 5x + 6 = 0`

This factors as:

`(x - 2)(x - 3) = 0`

So the roots are `2` and `3`.

### important note
A quadratic equation can have:
- two distinct real roots
- two equal real roots
- no real roots

## 3) solving by factorisation

This method works best when the expression can be split neatly.

### solved example
Solve:

`x^2 - 7x + 12 = 0`

Factorise:

`x^2 - 7x + 12 = (x - 3)(x - 4)`

So:
- `x - 3 = 0` or `x - 4 = 0`

Therefore:
- `x = 3` or `x = 4`

### memory trick
After factorisation, use zero-product rule:
If product is zero, at least one factor must be zero.

## 4) solving by completing the square

This method is systematic and very useful when factorisation is not easy.

### solved example
Solve:

`x^2 + 6x - 7 = 0`

Move constant:

`x^2 + 6x = 7`

Add `(6/2)^2 = 9` on both sides:

`x^2 + 6x + 9 = 7 + 9`

`(x + 3)^2 = 16`

Take square root:

`x + 3 = 4` or `x + 3 = -4`

So:
- `x = 1`
- `x = -7`

### important warning
When taking square root, never forget both `+` and `-`.

## 5) solving by quadratic formula

For:

`ax^2 + bx + c = 0`

the roots are:

`x = (-b +- sqrt(b^2 - 4ac)) / (2a)`

### solved example
Solve:

`2x^2 - 3x - 2 = 0`

Here:
- `a = 2`
- `b = -3`
- `c = -2`

Substitute:

`x = (3 +- sqrt(9 + 16)) / 4`

`x = (3 +- sqrt(25)) / 4`

`x = (3 +- 5) / 4`

So:
- `x = 2`
- `x = -1/2`

## 6) discriminant and nature of roots

The quantity:

`D = b^2 - 4ac`

is called the discriminant.

### what it tells us
- if `D > 0`, roots are real and distinct
- if `D = 0`, roots are real and equal
- if `D < 0`, roots are not real

This helps students predict the answer before solving fully.

## 7) applications of quadratic equations

Many word problems turn into quadratic equations.

Common examples:
- area problems
- number problems
- product of two consecutive numbers
- rectangle length and breadth relations

### basic method
1. define the unknown
2. build the equation carefully
3. solve the quadratic
4. reject impossible values if needed

## 8) exam-friendly summary notes

### must-know facts
- Standard form is `ax^2 + bx + c = 0`, with `a != 0`.
- Factorisation is the quickest method when possible.
- Completing the square is a step-by-step method.
- Quadratic formula works for every quadratic equation.
- Discriminant tells the nature of roots.

### one-line revision points
- quadratic means highest power is `2`
- factorise if easy
- square method if systematic work is needed
- formula always works if substitution is careful

## 9) common mistakes students make

1. Forgetting to write the equation in standard form first.
2. Missing the negative sign of `b` in the formula.
3. Taking only one square-root value instead of two.
4. Doing incomplete factorisation.
5. Keeping impossible values in word problems.

## 10) board tips

- Before solving, move all terms to one side and make the right side zero.
- In formula-based answers, write values of `a`, `b`, and `c` clearly.
- In completing-the-square method, show what number you added on both sides.
- In application problems, finish with a sentence, not only a value.

## 11) how to remember the chapter

### memory box 1
Quadratic means power `2`.

### memory box 2
Factorisation is the fastest path when the middle term can be split cleanly.

### memory box 3
Completing the square turns expression into a perfect square.

### memory box 4
Formula is the rescue method when factorisation is messy.

## 12) solved practice set

### question 1
Solve `x^2 - 9x + 20 = 0`.

Answer:
`(x - 4)(x - 5) = 0`
So roots are `4` and `5`.

### question 2
Solve `x^2 + 4x - 12 = 0` by completing the square.

Answer:
`x^2 + 4x = 12`
Add `4`:
`(x + 2)^2 = 16`
`x + 2 = +-4`
So `x = 2` or `x = -6`

### question 3
Find the discriminant of `3x^2 + 2x + 5 = 0`.

Answer:
`D = 2^2 - 4(3)(5) = 4 - 60 = -56`
So roots are not real.
