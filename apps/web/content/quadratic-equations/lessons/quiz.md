# Quadratic Equations chapter quiz

Answer these quick questions after revising the chapter notes.

## 1. Form

A quadratic equation is usually written as:

1. `ax^2 + bx + c = 0`
2. `ax + b = 0`
3. `a/x + b = 0`

Answer: 1
Explanation: A quadratic equation has the form `ax^2 + bx + c = 0`.

## 2. Degree

The degree of a quadratic equation is:

1. `1`
2. `2`
3. `3`

Answer: 2
Explanation: The highest power of the variable is 2, so the degree is 2.

## 3. Roots

The values that satisfy a quadratic equation are called:

1. factors
2. roots
3. coefficients

Answer: 2
Explanation: The values that make the equation true are called roots.

## 4. Nature of roots

The discriminant is:

1. `b^2 - 4ac`
2. `2a + 4b`
3. `a^2 + b^2 + c^2`

Answer: 1
Explanation: The discriminant of a quadratic equation is `b^2 - 4ac`.

## 5. Solving method

Which method is commonly used to solve some quadratic equations?

1. factorisation
2. long division
3. averaging

Answer: 1
Explanation: Factorisation is a common method for solving quadratic equations.
