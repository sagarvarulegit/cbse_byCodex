# Chapter Content Style QA Checklist

## Purpose

Use this checklist before calling a chapter pilot-ready, public-beta-ready, or ready for a student review session.

It applies to Class 10 chapter notes, lesson-wise pilot pages, and generated chapter packs.

## When To Use This

Use it:

- before publishing a new lesson-wise chapter
- before widening a chapter beyond the tiny pilot
- after generating or importing a chapter pack
- after major edits to notes, examples, quiz links, or recap content

## Quick Pass Checklist

| Check | Pass Rule | Status |
| --- | --- | --- |
| Easy scanning | Main ideas, examples, practice, and recap are easy to spot at a glance. | Todo |
| Short sections | Each section teaches one idea and avoids long walls of text. | Todo |
| Example after concept | Every major concept is followed by a concrete example. | Todo |
| Memory trick | At least one hard-to-remember idea has a short recall line when useful. | Todo |
| Common mistake | The chapter warns about a likely mistake and shows the fix. | Todo |
| Board tip | The chapter gives a direct exam-habit or presentation tip. | Todo |
| Practice prompt | The page gives the student something quick to try immediately. | Todo |
| Recap | The recap is short, useful, and does not introduce brand-new content. | Todo |

## Detailed Checklist

### 1. Easy Scanning

- What to check:
  - headings are clear
  - long paragraphs are broken up
  - important formulas, reactions, keywords, or terms stand out
  - a student can find the next action quickly
- Pass rule:
  - A student can scan the page in under 30 seconds and identify the main concepts, examples, practice, and recap.
- Fix if missing:
  - split the block
  - add a stronger heading
  - move one key point into a list or a callout
- Tiny example:
  - Good heading: `Why balancing equations matters`
  - Weak heading: `Explanation`

### 2. Short Sections

- What to check:
  - each section teaches one idea
  - section body is short enough for mobile reading
  - lists are used for steps, features, mistakes, or rules
- Pass rule:
  - No section feels like a wall of text; split anything that mixes two concepts.
- Fix if missing:
  - split one section into two or three smaller blocks
  - move the example or exception into its own block
- Tiny example:
  - Split `Definition + example + exception` into three small blocks.

### 3. Example After Concept

- What to check:
  - every major concept is followed by one solved or concrete example
  - the example uses Class 10 level language
  - the example is close to board-question style when possible
- Pass rule:
  - After learning a concept, the student immediately sees how it is used.
- Fix if missing:
  - add one worked example right after the concept
  - keep the wording plain and direct
- Tiny example:
  - Concept: Combination reaction.
  - Example: Calcium oxide combines with water to form calcium hydroxide.

### 4. Memory Trick

- What to check:
  - memory trick is short
  - it helps recall, not distract
  - it is accurate and not childish for Class 10
- Pass rule:
  - At least one hard-to-remember idea has a compact memory line.
- Fix if missing:
  - add one line that is easy to repeat
  - keep it tied to a real rule or pattern
- Tiny example:
  - Memory line: `OIL RIG means Oxidation Is Loss, Reduction Is Gain.`

### 5. Common Mistake

- What to check:
  - names the mistake directly
  - explains why it is wrong
  - gives a corrected version or quick fix
- Pass rule:
  - The chapter warns students about at least one mistake they are likely to make in practice or exams.
- Fix if missing:
  - add a direct warning with a corrected version
  - keep the fix short and obvious
- Tiny example:
  - Mistake: Changing chemical formulas while balancing.
  - Fix: Change coefficients only.

### 6. Board Tip

- What to check:
  - focuses on exam presentation, keywords, steps, units, diagrams, or answer framing
  - does not make unsupported claims about exact future board questions
  - uses direct student-facing language
- Pass rule:
  - The tip helps the student score better on a written answer without guessing the paper.
- Fix if missing:
  - turn a vague note into a direct exam habit
  - avoid prediction language
- Tiny example:
  - Board tip: Write the balanced equation before naming the reaction type.

### 7. Practice Prompt

- What to check:
  - gives the student something to do immediately
  - is short enough to try without leaving the page
  - includes an answer check when the prompt has a definite answer
- Pass rule:
  - Every chapter or lesson has at least one quick practice task before the recap.
- Fix if missing:
  - add one question, one balancing task, or one short board-style prompt
  - include a check line for fixed-answer questions
- Tiny example:
  - Practice: Balance `Fe + O2 -> Fe2O3`.
  - Answer check: `4Fe + 3O2 -> 2Fe2O3`.

### 8. Recap

- What to check:
  - recap is short
  - recap repeats the highest-value ideas
  - comic recap or visual recap remains understandable if styling fails
  - lesson-wise comic recap keeps the expected `## Comic recap` heading and quoted panel list shape when used
- Pass rule:
  - A student can revise the page from the recap in 1 minute.
- Fix if missing:
  - remove extra detail
  - keep only the key idea, rule, mistake, and action
- Tiny example:
  - Recap: Define the idea, remember the rule, avoid the common mistake, try one question.

## Per-Chapter Review Template

| Chapter | Easy scanning | Short sections | Example after concept | Memory trick | Common mistake | Board tip | Practice prompt | Recap | Decision | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `<chapter name>` | Todo | Todo | Todo | Todo | Todo | Todo | Todo | Todo | Fix needed | `<what to fix first>` |

Allowed statuses:

- `Pass`
- `Fix needed`
- `Not applicable`
- `Todo`

Decision values:

- `Ready for pilot`
- `Fix needed`
- `Needs subject review`
- `Do not publish`

## Pass Or Fix Decision

- A chapter cannot be called pilot-ready if easy scanning, example after concept, practice prompt, and recap are missing.
- A chapter can still pass if memory trick is `Not applicable`, but only when there is no formula, definition, sequence, reaction type, grammar rule, or exam pattern worth remembering.
- A board tip must not invent CBSE predictions. It should focus on presentation and exam habits.
- A recap must not introduce brand-new content.
- For English literature chapters, preserve uncertainty and story nuance instead of forcing a fake moral or final answer.

## Out Of Scope

- Do not rewrite all 76 generated chapter packs.
- Do not change Next.js routes, React components, CSS, quiz scoring, mastery logic, or API code.
- Do not add a database table for content QA.
- Do not add payments or subscription work.
- Do not claim real student pilot evidence.
