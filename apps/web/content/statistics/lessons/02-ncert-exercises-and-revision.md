# NCERT Exercises and Chapter Revision

## Exercise 13.1

The nine mean questions use grouped tables about plants, wages, pocket allowance, heartbeats, mango boxes, household food expenditure, sulphur-dioxide concentration, teacher absence and literacy rates.

Every answer should show:

1. class marks $x_i$
2. selected method
3. completed $f_ix_i$, $f_id_i$ or $f_iu_i$ column
4. both totals
5. final mean with its unit and interpretation

## Exercise 13.2

The six mode questions cover ages of hospital patients, component lifetimes, household expenditure, student-teacher ratios, runs by batsmen, and cars passing a point.

Method:

1. identify the modal class from the maximum frequency
2. record $l,h,f_0,f_1,f_2$
3. substitute once into the mode formula
4. interpret the approximate value

## Exercise 13.3

The seven median questions use electricity consumption, missing frequencies, policyholder ages, leaf lengths, neon-lamp lifetimes, surnames and student weights.

Method:

1. make classes continuous if necessary
2. calculate cumulative frequencies
3. find $n/2$
4. identify the median class
5. record $l,cf,f,h$
6. use the formula

For missing-frequency problems, use both the total-frequency equation and the given median equation.

## Common mistakes

- adding class marks instead of frequencies to find $n$
- using the class with cumulative frequency below $n/2$ as the median class
- forgetting that grouped answers are estimates

## Board-answer checklist

- Full working table
- Formula and symbol meanings clear
- Correct class selected
- Final value interpreted in context

## One-minute revision

The formula is the last step; the working table and correct class choice do most of the thinking.

## Comic recap

- Table: "Complete me before substituting."
- Mean: "Multiply frequency by class mark."
- Mode: "Use my class and both neighbours."
- Median: "Cumulative frequency finds my class."
