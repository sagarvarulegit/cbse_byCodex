# Real Numbers Mini Quiz

## Questions (choose the correct option)

1. **140** in prime‑factor form is:
   - a) `2 × 2 × 5 × 7` ✅
   - b) `2 × 3 × 5 \times 7`
   - c) `2 × 2 \times 7 \times 7`
   - d) `5 × 5 × 7`

2. HCF of **26** and **91** is:
   - a) `7`
   - b) `13` ✅
   - c) `26`
   - d) `91`

3. Which number is irrational?
   - a) `0.75`
   - b) `7/9`
   - c) `√5` ✅
   - d) `-3`

4. Which denominator gives a terminating decimal (in lowest form)?
   - a) `12`
   - b) `15`
   - c) `20` ✅
   - d) `21`

5. In Euclid’s method, when the remainder becomes zero, the answer is:
   - a) quotient
   - b) dividend
   - c) last divisor ✅
   - d) first divisor

**Answer key**
1. a 2. b 3. c 4. c 5. c
