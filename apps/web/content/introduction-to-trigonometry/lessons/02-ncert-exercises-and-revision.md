# NCERT Exercises and Chapter Revision

## Exercise 8.1

The eleven questions practise:

- all six ratios from a labelled right triangle
- conversion between reciprocal and quotient ratios
- finding ratios from one given ratio
- proving two acute angles equal
- evaluating rational expressions of ratios
- checking statements about standard values and reciprocal pairs

Figure 8.13 belongs to the first question. Use its printed side labels; do not guess the reference angle.

## Exercise 8.2

This four-question set uses Table 8.1. It includes direct evaluations, justified multiple choice, finding angles from $\tan(A+B)$ and $\tan(A-B)$, and true/false reasoning.

Before calculating, write each standard value exactly. Rationalise or simplify only after substitution.

## Exercise 8.3

The four questions practise identities. A safe proof structure is:

1. write `LHS`
2. factor, rationalise or convert reciprocal ratios
3. use one of the three identities
4. stop when the expression is exactly `RHS`

Never begin with `LHS = RHS`; that assumes what you are meant to prove.

## Common mistakes

- cancelling terms across addition or subtraction
- taking a positive square root without checking the acute-angle condition
- using a standard value from the wrong row

## Board-answer checklist

- Reference angle and side names clear
- Exact values used
- Identity steps flow from one side only
- Undefined ratios handled honestly

## One-minute revision

Ratios come from triangles; values come from special triangles; identities come from Pythagoras.

## Comic recap

- Triangle: "Label me before using a ratio."
- Table 8.1: "Read my row and column carefully."
