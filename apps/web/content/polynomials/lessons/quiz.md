# Polynomials chapter quiz

Answer these quick questions after revising the chapter notes.

## 1. Basic idea

A polynomial in one variable is:

1. an expression made from variables, constants, and powers with whole number exponents
2. only a number with no variable
3. a fraction with no algebra

Answer: 1
Explanation: A polynomial uses variables, constants, and whole-number exponents.

## 2. Zeroes of a polynomial

If `p(x) = 0` for a value of `x`, that value is called:

1. the coefficient
2. the zero of the polynomial
3. the degree of the polynomial

Answer: 2
Explanation: A value that makes the polynomial zero is called a zero of the polynomial.

## 3. Degree

The degree of `3x^4 - 2x + 7` is:

1. `1`
2. `4`
3. `7`

Answer: 2
Explanation: The highest power of x is 4, so the degree is 4.

## 4. Linear polynomial

Which is a linear polynomial?

1. `x + 5`
2. `x^2 + 5`
3. `x^3 + 1`

Answer: 1
Explanation: A linear polynomial has degree 1, so `x + 5` fits.

## 5. Remainder idea

If a polynomial `p(x)` is divided by `x - a`, the remainder is:

1. `p(a)`
2. `a - p(x)`
3. always zero

Answer: 1
Explanation: By the remainder theorem, the remainder is `p(a)`.
