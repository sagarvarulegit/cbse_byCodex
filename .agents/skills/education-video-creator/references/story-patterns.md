# Story and visual teaching patterns

Select one primary pattern. Add a secondary pattern only when it solves a different learning problem.

## Mystery to mechanism

Use for surprising everyday effects.

```text
Unexpected result -> prediction -> visible evidence -> invisible cause -> formal name -> new prediction
```

Avoid presenting the surprise as proof. Reveal the missing causal link before naming the phenomenon.

## Clumsy solution to elegant solution

Use when the final design makes more sense after seeing a plausible failure.

```text
Goal -> obvious attempt -> failure cost -> missing insight -> elegant solution -> payoff
```

Keep the failed attempt physically and scientifically plausible. Do not invent fake engineering history or attribute the sequence to a real inventor without evidence.

## Macro to micro to macro

Use for particles, cells, fields, forces, reactions, and material changes.

```text
Observable event -> zoom inside -> track one mechanism -> zoom out -> explain the original event
```

Preserve orientation during the zoom. Make microscopic entities schematic rather than falsely photorealistic.

## Misconception reversal

Use when students commonly apply an intuitive but incorrect rule.

```text
Common prediction -> counterexample -> conflict -> corrected rule -> boundary case
```

Let the learner commit to a prediction before revealing the correction. State when the original intuition remains useful.

## Journey through a process

Use for circulation, digestion, transport, manufacturing, algorithms, historical chains, or narrative sequence.

```text
Traveler/object enters -> state changes at each station -> destination -> whole-route recap
```

Keep the traveler and direction consistent. Show why each station changes the state.

## Compare under controlled change

Use for experiments, graphs, grammar contrasts, geometry, and cause-effect comparisons.

```text
Same starting state -> change one variable -> compare outcomes -> state the relationship
```

Visually hold all other variables constant. Do not imply causation when the source supports only association.

## Build-up and threshold

Use for accumulation, equilibrium, pressure, charge, population, feedback, and tipping points.

```text
Small repeated change -> visible accumulation -> threshold -> rapid consequence -> control or recovery
```

Show the scale and units when the threshold is quantitative.

## Worked problem as a detective story

Use for mathematics, chemical equations, circuits, grammar, and source analysis.

```text
Question -> known clues -> choose rule -> perform one transformation -> check -> explain why it works
```

Do not animate directly to the answer. Preserve student-visible intermediate work and the verification step.

## Visual grammar

- Assign one meaning to each colour, shape, line style, sound, and motion.
- Use motion direction to represent a real directional relationship.
- Use quantity, length, position, or count when teaching magnitude; do not use decorative scale changes.
- Keep the main object in a stable screen region unless movement itself teaches the idea.
- Highlight only the object involved in the current causal step.
- Use arrows for direction, traces for paths, pulses for transfer, and counters for conservation.
- Prefer cutaways, transparent layers, or scale transitions over floating labels with no spatial anchor.
- Return to the opening composition for the final payoff so the learner can compare before and after.

## Cognitive-load guardrails

- Introduce no more labels than the learner needs for the current step.
- Avoid simultaneous narration, captions, labels, and motion that each introduce different facts.
- Break long mechanisms at natural causal boundaries, not arbitrary time intervals.
- Repeat the relationship with a new representation, not the same sentence three times.
- Prefer continuity of objects over constant scene changes.
- Use humour after orientation, not during a fragile explanation.

## Originality guardrails

Extract instructional principles from reference videos, not their protected expression. Do not reproduce another creator's character, shot sequence, narration, distinctive visual design, or punchline beat for beat. Build an original story from the textbook mechanism and the platform's own visual language.
