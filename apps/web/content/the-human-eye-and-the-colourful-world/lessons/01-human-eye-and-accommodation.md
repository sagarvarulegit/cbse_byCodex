# 10.1 The Human Eye

<ActivityIllustration demoId="figure-10-1-human-eye" />

| Part | Exact function |
|---|---|
| cornea | transparent front bulge; performs most refraction |
| iris | dark muscular diaphragm controlling pupil size |
| pupil | opening that regulates light entering |
| crystalline lens | fine adjustment of focus |
| ciliary muscles | change lens curvature and focal length |
| retina | light-sensitive screen; real inverted image forms here |
| light-sensitive cells | convert light stimulation into electrical signals |
| optic nerve | carries signals to brain |
| brain | interprets signals so we perceive the scene |

Eyeball diameter is about `2.3 cm`.

# 10.1.1 Power of Accommodation

Accommodation is the eye's ability to change the eye-lens focal length so
objects at different distances focus sharply on the retina.

- distant object: ciliary muscles relax -> lens thin -> focal length increases;
- nearby object: muscles contract -> curvature and thickness increase -> focal
  length decreases.

For a normal young adult:

- far point = infinity;
- near point/least distance of distinct vision = about 25 cm.

Below 25 cm, a normal eye cannot increase lens curvature enough; the image
cannot be focused comfortably and angular strain increases.

When object distance changes, the retina stays fixed, so **image distance inside
the eye remains essentially constant**; accommodation changes focal length.

## Eye donation source note

NCERT's awareness box states eyes should be removed within 4–6 hours of death
through an eye bank; removal takes about 10–15 minutes, does not disfigure the
face, and one donated pair can give vision to up to four corneal-blind people.
Follow current medical/eye-bank instructions in real life.
