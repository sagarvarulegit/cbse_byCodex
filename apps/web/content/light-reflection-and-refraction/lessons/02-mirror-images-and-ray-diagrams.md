# 9.2.1 Image Formation by Spherical Mirrors

## Concave mirror image table

| Object position | Image position | Size | Nature |
|---|---|---|---|
| infinity | F | highly diminished, point-sized | real, inverted |
| beyond C | between C and F | diminished | real, inverted |
| at C | at C | same | real, inverted |
| between C and F | beyond C | enlarged | real, inverted |
| at F | infinity | highly enlarged; no finite screen image | real, inverted |
| between F and P | behind mirror | enlarged | virtual, erect |

# 9.2.2 Four standard mirror rays

Use any two:

1. parallel to axis -> through F for concave; appears from F for convex;
2. through/directed toward F -> parallel to axis;
3. through/directed toward C -> retraces its path;
4. at pole P -> reflects with `i = r`.

Real reflected rays are solid. Extend diverging reflected rays backward with
dashes to locate a virtual image. Arrowheads must show light direction.

## Activities 9.3–9.6

- Place a candle at all six positions, locate screen images, and tabulate
  position, size, orientation, and nature.
- A virtual image between P and F cannot be obtained on a screen.
- As an object moves away from a convex mirror, its erect diminished image
  moves toward F and becomes smaller.
- A small convex mirror shows a large area because it provides a wide field of
  view.

## Uses with reason

- concave: torch/headlight reflector (parallel beam), shaving/dentist mirror
  (erect magnified near image), solar furnace (concentrates sunlight);
- convex: rear-view mirror (wide field, erect diminished image).

## Diagram checklist

Draw axis first; mark P, F, C in correct order; place object; use two valid rays;
mark the intersection; draw image with correct arrow; label real/virtual,
erect/inverted, and size.
