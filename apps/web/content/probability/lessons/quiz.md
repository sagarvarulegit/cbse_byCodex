# Probability chapter quiz

Answer these quick questions after revising the chapter notes.

## 1. Meaning

Probability measures:

1. certainty only
2. chance of an event
3. distance between events

## 2. Range

The probability of an event is always between:

1. `-1` and `1`
2. `0` and `1`
3. `1` and `10`

## 3. Certain event

A certain event has probability:

1. `0`
2. `1`
3. `1/2`

## 4. Impossible event

An impossible event has probability:

1. `0`
2. `1`
3. `2`

## 5. Formula idea

Basic probability is:

1. favourable outcomes / total outcomes
2. total outcomes / favourable outcomes
3. favourable outcomes + total outcomes
