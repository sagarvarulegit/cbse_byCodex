# Reading Skills - Discursive Passage

## chapter goal

Build a calm method for reading a 400-450 word discursive passage and answering inference, vocabulary, and short-answer questions.

## teacher note on textbook alignment

This pack supports the English Language and Literature reading domain. It is a skill note, not a copied passage bank.

## chapter flow for the platform

1. Read the central argument.
2. Separate fact, opinion, and example.
3. Answer inference questions with evidence.
4. Use context for vocabulary.
5. Revise common traps.

## 1) what a discursive passage does

A discursive passage discusses an idea. It may explain both sides, give reasons, or persuade the reader.

Read for the writer's main point first. Details make sense only after the main point is clear.

## 2) first reading method

Read the first and last paragraph carefully. They often reveal the topic, purpose, and conclusion.

While reading, mark words that show contrast, cause, result, example, and conclusion.

## 3) inference method

Inference means finding what is suggested, not directly stated.

Use this answer frame: The passage suggests this because the writer mentions this evidence.

## 4) vocabulary in context

Do not choose a meaning only because it is familiar. Choose the meaning that fits the sentence.

Check the word before it, the word after it, and the paragraph mood.

## exam-friendly summary notes

- A discursive passage develops an idea or argument.
- Find the main point before answering details.
- Inference must be supported by passage evidence.
- Vocabulary questions depend on context.
- Avoid outside knowledge unless the question asks for it.

## common mistakes students make

1. Copying full lines without answering the question.
2. Using personal opinion where passage evidence is needed.
3. Ignoring words like however, therefore, because, and although.

## board tips

- Underline command words such as explain, infer, identify, and support.
- Keep short answers direct.
- For MCQs, eliminate options that are too extreme or not present in the passage.

## short answer practice

1. What is the main aim of a discursive passage?
2. Why should inference answers include evidence?
3. How can contrast words help in reading?
4. What should you check before answering vocabulary questions?

## mini quiz with answers

1. A discursive passage discusses an idea.
2. Inference is based on clues in the passage.
3. Context helps vocabulary questions.
4. Personal opinion should not replace passage evidence.
5. Command words tell you what kind of answer is needed.
