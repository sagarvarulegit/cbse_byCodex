# Class 10 Hindi Course B Chapter Packs

This folder contains draft notes for Hindi Course B.

The notes are grouped by domain:

- Board skills: अपठित गद्यांश, व्यावहारिक व्याकरण, and रचनात्मक लेखन.
- Sparsh, भाग-2: prose and poetry notes based on the local `hindi-sparsh.zip` textbook source.
- Sanchayan, भाग-2: supplementary reading notes backed by local NCERT Reprint 2026-27 PDFs in `textbooks/hindi-sanchayan/`.

Each pack is a simplified revision note. Exact textbook question wording and source-faithful trackers still need a later review pass before these packs can be called source-faithful.
