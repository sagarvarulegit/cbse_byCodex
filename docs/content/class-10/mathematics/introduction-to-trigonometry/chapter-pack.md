# Introduction to Trigonometry

This is an original teaching draft for Class 10 Mathematics, Chapter 8. The chapter becomes manageable when each ratio is tied to a side of a right triangle instead of being memorised blindly.

## chapter goal

By the end of this chapter, a student should be able to:
- identify opposite side, adjacent side, and hypotenuse
- write all six trigonometric ratios
- use ratios for standard angles
- apply basic trigonometric identities
- solve simple ratio-based questions correctly

## teacher note on textbook alignment

The current NCERT Class 10 chapter strongly focuses on:
- trigonometric ratios of an acute angle
- relation between ratios
- values at `0 deg`, `30 deg`, `45 deg`, `60 deg`, and `90 deg`
- identities involving `sin`, `cos`, `tan`, `cosec`, `sec`, and `cot`

1. Right triangle language
2. Six trigonometric ratios
3. Ratios for complementary angles
4. Standard angle values
5. Trigonometric identities

## 1) right triangle language

In a right triangle:
- hypotenuse is the side opposite the right angle
- opposite side is opposite the chosen acute angle
- adjacent side is the remaining side next to the chosen acute angle

### important point
Opposite and adjacent change when the chosen angle changes.
Hypotenuse does not change.

## 2) six trigonometric ratios

For an acute angle `theta`:

- `sin theta = opposite / hypotenuse`
- `cos theta = adjacent / hypotenuse`
- `tan theta = opposite / adjacent`
- `cosec theta = hypotenuse / opposite`
- `sec theta = hypotenuse / adjacent`
- `cot theta = adjacent / opposite`

### memory help
- sine starts with opposite
- cosine starts with adjacent
- tangent compares opposite and adjacent

## 3) ratios of complementary angles

If two acute angles are complementary, their sum is `90 deg`.

Important relations:
- `sin theta = cos (90 deg - theta)`
- `cos theta = sin (90 deg - theta)`
- `tan theta = cot (90 deg - theta)`
- `cosec theta = sec (90 deg - theta)`
- `sec theta = cosec (90 deg - theta)`
- `cot theta = tan (90 deg - theta)`

These results come from looking at the same right triangle from the other acute angle.

## 4) standard angle values

Students must know these values:

- `sin 0 deg = 0`, `cos 0 deg = 1`
- `sin 30 deg = 1/2`, `cos 30 deg = sqrt(3)/2`
- `sin 45 deg = 1/sqrt(2)`, `cos 45 deg = 1/sqrt(2)`
- `sin 60 deg = sqrt(3)/2`, `cos 60 deg = 1/2`
- `sin 90 deg = 1`, `cos 90 deg = 0`

From these:

- `tan 0 deg = 0`
- `tan 45 deg = 1`
- `tan 60 deg = sqrt(3)`

### warning
`tan 90 deg` is not defined because `cos 90 deg = 0`.

## 5) trigonometric identities

Main identities:

- `sin^2 theta + cos^2 theta = 1`
- `1 + tan^2 theta = sec^2 theta`
- `1 + cot^2 theta = cosec^2 theta`

These are used to simplify expressions and prove results.

### solved example
If `tan theta = 3/4`, find `sec theta`.

Using:

`1 + tan^2 theta = sec^2 theta`

`1 + 9/16 = sec^2 theta`

`25/16 = sec^2 theta`

`sec theta = 5/4`

## 6) exam-friendly summary notes

### must-know facts
- Ratios are defined in a right triangle.
- Opposite and adjacent depend on the chosen acute angle.
- Standard angle values must be remembered accurately.
- `sin` and `cos` are linked by complementary angles.
- Identities help simplify and prove expressions.

### one-line revision points
- hypotenuse stays fixed
- angle changes opposite and adjacent
- standard values are board-scoring memory items

## 7) common mistakes students make

1. Mixing opposite and adjacent sides.
2. Forgetting that the chapter uses right triangles.
3. Writing wrong standard values for `30 deg` and `60 deg`.
4. Saying `tan 90 deg = infinity` instead of saying it is not defined.
5. Using the wrong identity in simplification.

## 8) board tips

- Draw and label the triangle before writing ratios.
- In identity questions, start from one side only.
- Write standard values neatly from memory and avoid guessing.
- Rationalise denominators if the form demands it.

## 9) how to remember the chapter

### memory box 1
Trigonometry is only side ratios around an angle.

### memory box 2
Opposite means directly facing the angle.

### memory box 3
`30 deg`, `45 deg`, and `60 deg` are the main scoring angles.

### memory box 4
Identity questions are usually substitution plus simplification.

## 10) solved practice set

### question 1
If opposite = `3` and hypotenuse = `5`, find `sin theta`.

Answer:
`sin theta = 3/5`

### question 2
Find `cos 60 deg`.

Answer:
`cos 60 deg = 1/2`

### question 3
If `sin theta = 5/13`, find `cos theta`.

Answer:
Use triangle or identity:
`cos theta = 12/13`

## 11) short answer practice

1. What changes when the acute angle changes in a right triangle?
2. Why is `tan 90 deg` not defined?
3. State the identity involving `sin` and `cos`.
4. What is the relation between `sin theta` and `cos (90 deg - theta)`?
5. Why are standard values important?
