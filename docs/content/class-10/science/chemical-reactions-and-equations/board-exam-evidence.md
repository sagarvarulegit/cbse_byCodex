# Chemical Reactions and Equations Board Exam Evidence

## Decision

Historical board papers show that Chapter 1 knowledge is repeatedly assessed
through constructed answers, not only MCQs. The platform therefore keeps the
20-question concept quiz and adds three separate lesson surfaces:

- `07-board-exam-practice.md` for verified previous-year questions and
  marking-point answers
- `08-board-readiness-diagnostic.md` for an original 30-mark mixed-format paper
- `09-board-readiness-diagnostic-b.md` for a second original 20-mark transfer
  check targeting electrolysis ratios and unfamiliar redox agents

The six NCERT lessons remain the canonical textbook path. The new files are
unnumbered platform supplements and must never be presented as NCERT sections.

## Extraction limitations

The generated dataset is useful for search but not safe as a publication
source by itself. Observed limitations include:

- damaged Hindi, Punjabi and figure text
- adjacent questions merged into one record
- incorrect discipline labels
- question-number and mark mismatches
- duplicate set variants
- equations losing subscripts, arrows or state symbols

Publication rule: do not label extracted wording as a verified previous-year
question until the original PDF page has been rendered and visually checked.

## Marking-guide rule

For the nine published PYQs, the platform possesses and has checked the
matching official marking schemes. Student answers still use the label
**Platform marking points** because they paraphrase the official value points,
add explanatory reasoning and do not reproduce CBSE's evaluator document or
claim an official mark split. Any future PYQ must pass both gates before
publication: visual verification against the original question-paper page and
value-point verification against the official marking scheme when available.

## Implementation learnings

- Concept completeness and exam readiness are different gates. The six NCERT
  lessons covered the science, but historical papers exposed a response-format
  gap in integrated 2-, 3- and 5-mark answers.
- A concept quiz and board-readiness diagnostics should remain separate. The
  quiz checks broad recall and misconceptions. Diagnostic A checks timed written
  completeness, while Diagnostic B checks whether learning transfers after the
  first answer set is familiar.
- Historical papers exposed two electrolysis distinctions that a textbook-only
  summary can miss: acid improves conductivity, and the gas ratio is `2:1` by
  volume but `1:8` by mass in cathode:anode order.
- Official value-point review exposed two easy-to-lose half-mark phrases:
  explicitly state endothermic/exothermic when asked to compare reaction
  patterns, and state the milky-white observation when carbon dioxide is passed
  through calcium hydroxide. Equations alone should not be assumed to communicate
  every requested observation or classification.
- One familiar `CuO + H₂` example is not enough evidence of redox-agent
  transfer. The board bridge now uses a two-pass method and visually verified
  unfamiliar equations.
- Adding live supplement lessons affects navigation, lesson counts, chapter
  duration and strict quiz-topic validation. These consumers must be reviewed
  together while the concept quiz stays scoped to the six core lesson slugs.
- A single hidden `Answer check` section per supplement gives students a clear
  attempt-first boundary and avoids multiple repeated disclosure targets.
- A total score alone is weak diagnostic evidence. Recording the first failure
  among balancing, observation, equation, classification, reason, redox agent
  and multi-part completion gives a usable revision action.
- Each PYQ and current-pattern challenge now has a write-before-check marker.
  The rendered card keeps answer text on the student's device and persists only
  the selected marking points, half-mark score, weak skills, answer length and
  attempt identity. Every unticked skill links to an exact lesson remediation
  section before the student starts a fresh attempt.
- PDF-render verification is necessary even when extracted English text looks
  clean, because equations, marks, OR choices and page boundaries can still be
  merged or damaged.
- Board-practice additions must be included in holdout-leak checks. Good
  historical coverage must not invalidate the independent transfer gate.

## Reuse rule for later chapters

1. Complete the current-textbook map first.
2. Search historical papers only after source fidelity is stable.
3. Treat extraction as discovery, not verification.
4. Render and inspect every quoted paper page.
5. Keep verified PYQs separate from original board-style questions.
6. Preserve a question's year, paper code, number and printed page.
7. Never use historical frequency as the current blueprint unless a current
   official source explicitly supports that conclusion.
8. Add a diagnostic only when its marks, answer key and remediation path are
   internally consistent.
