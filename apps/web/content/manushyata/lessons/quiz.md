# Manushyata chapter quiz

Answer these quick questions after revising the chapter notes.

## 1. Main idea

Manushyata means:

1. humanity
2. industry
3. trade

Answer: 1
Explanation: Manushyata means humanity.

## 2. True humanity

The poem values:

1. selfless service
2. selfishness
3. pride only

Answer: 1
Explanation: The poem values selfless service to others.

## 3. Brotherhood

The poem supports:

1. universal brotherhood
2. hatred
3. isolation only

Answer: 1
Explanation: The poem calls for universal brotherhood among people.

## 4. Historical examples

The poem uses examples to inspire:

1. sacrifice and service
2. carelessness
3. greed

Answer: 1
Explanation: The examples are used to inspire sacrifice and service.

## 5. Message

A good human being should:

1. live for others too
2. ignore society
3. seek only comfort

Answer: 1
Explanation: The message is to live for others and not only for oneself.
