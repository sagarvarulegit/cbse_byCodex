# Pair of Linear Equations in Two Variables

This is an original teaching draft for Class 10 Mathematics, Chapter 3. The aim is to make equation-solving feel systematic instead of random.

## chapter goal

By the end of this chapter, a student should be able to:
- identify a linear equation in two variables
- understand the graphical meaning of a pair of equations
- solve a pair of linear equations by substitution
- solve a pair of linear equations by elimination and cross-multiplication
- decide whether the pair has one solution, no solution, or infinitely many solutions

## 1) linear equation in two variables

A linear equation in two variables can be written as:

`ax + by + c = 0`

where `a` and `b` are not both zero.

Examples:
- `2x + 3y = 7`
- `x - 4y = 9`

The graph of a linear equation is a straight line.

## 2) pair of equations

When two such equations are taken together, we get a pair of linear equations in two variables.

Example:
- `2x + y = 5`
- `x - y = 1`

We want the value of `x` and `y` that satisfies both equations together.

That common ordered pair is the solution.

## 3) graphical meaning of solution

Each equation gives one straight line.
The solution depends on how the two lines behave.

### case 1: intersecting lines
If the lines meet at one point, there is one unique solution.

Condition:
`a1/a2 != b1/b2`

### case 2: parallel lines
If the lines never meet, there is no solution.

Condition:
`a1/a2 = b1/b2 != c1/c2`

### case 3: coincident lines
If the lines lie on top of each other, there are infinitely many solutions.

Condition:
`a1/a2 = b1/b2 = c1/c2`

### memory trick
One crossing -> one answer
Never crossing -> no answer
Same line -> many answers

## 4) substitution method

### steps
1. Make one variable the subject in one equation.
2. Put that value into the other equation.
3. Solve for one variable.
4. Substitute back to get the second variable.

### solved example
Solve:
- `x + y = 7`
- `x - y = 1`

From first equation:
`x = 7 - y`

Substitute into second:
`(7 - y) - y = 1`
`7 - 2y = 1`
`-2y = -6`
`y = 3`

Now:
`x = 7 - 3 = 4`

So solution is `(4, 3)`.

## 5) elimination method

In this method, we make the coefficients of one variable equal and then remove that variable.

### solved example
Solve:
- `2x + 3y = 13`
- `3x + 2y = 12`

Multiply first equation by `3`:
`6x + 9y = 39`

Multiply second equation by `2`:
`6x + 4y = 24`

Subtract:
`5y = 15`
`y = 3`

Put into `3x + 2y = 12`:
`3x + 6 = 12`
`3x = 6`
`x = 2`

So solution is `(2, 3)`.

## 6) cross-multiplication method

For:

`a1x + b1y + c1 = 0`

`a2x + b2y + c2 = 0`

the solution is:

`x / (b1c2 - b2c1) = y / (c1a2 - c2a1) = 1 / (a1b2 - a2b1)`

This method is useful when students are comfortable with careful sign handling.

### warning
One sign mistake can spoil the full answer. Write each bracket clearly.

## 7) equations reducible to linear form

Some word problems or fraction equations look difficult first, but after simplification they become linear.

Example idea:
`1/x + 1/y = something`

If a substitution is given like `u = 1/x` and `v = 1/y`, the equation may become linear in `u` and `v`.

Students should first simplify before choosing a method.

## 8) exam-friendly summary notes

### must-know facts
- A linear equation in two variables has a straight-line graph.
- Solution of a pair means a common point on both lines.
- Intersecting lines give one solution.
- Parallel lines give no solution.
- Coincident lines give infinitely many solutions.
- Substitution, elimination, and cross-multiplication are all valid methods.

### one-line revision points
- solve both together, not separately
- graph tells the nature of the answer
- equal ratio test gives consistency

## 9) common mistakes students make

1. Solving one equation and stopping there.
2. Mixing up the conditions for no solution and infinitely many solutions.
3. Forgetting to multiply every term during elimination.
4. Making sign errors in cross-multiplication.
5. Reading the graph wrongly and giving an approximate answer far from the true intersection.

## 10) board tips

- Write the pair in standard form before using ratio conditions.
- In graph questions, mark scale and coordinates clearly.
- In algebraic methods, write each transformed equation on a new line.
- After finding `x` and `y`, check them in both original equations.

## 12) solved practice set

### question 1
Solve:
- `x + y = 10`
- `x - y = 4`

Answer:
Add the equations:
`2x = 14`
`x = 7`

Then `y = 3`

### question 2
Check the nature of solution:
- `2x + 4y = 8`
- `x + 2y = 5`

Answer:
`a1/a2 = 2/1 = 2`
`b1/b2 = 4/2 = 2`
`c1/c2 = -8/-5 = 8/5`

So:
`a1/a2 = b1/b2 != c1/c2`

No solution.

### question 3
Solve:
- `3x + y = 11`
- `x + y = 7`

Answer:
Subtract second from first:
`2x = 4`
`x = 2`

Then `y = 5`
