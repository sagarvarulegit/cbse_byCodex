# Introduction to Trigonometry chapter quiz

## 1. Sine ratio

For an acute angle $A$ in a right triangle, $\sin A$ equals:

1. adjacent/hypotenuse
2. opposite/hypotenuse
3. opposite/adjacent
4. hypotenuse/opposite

Answer: 2
Topic: core-notes
Difficulty: easy
Source: NCERT Section 8.2 aligned
Explanation: Sine compares the side opposite the angle with the hypotenuse.

## 2. Tangent ratio

For an acute angle $A$, $\tan A$ equals:

1. $\sin A/\cos A$
2. $\cos A/\sin A$
3. $1/\sin A$
4. $1/\cos A$

Answer: 1
Topic: core-notes
Difficulty: easy
Source: NCERT Section 8.2 aligned
Explanation: Both definitions simplify to opposite/adjacent.

## 3. Standard value

$\sin 30^\circ$ is:

1. $0$
2. $1/2$
3. $1/\sqrt2$
4. $\sqrt3/2$

Answer: 2
Topic: core-notes
Difficulty: easy
Source: NCERT Section 8.3 aligned
Explanation: The standard-value table gives $\sin30^\circ=1/2$.

## 4. Undefined value

Which standard trigonometric value is not defined?

1. $\sin90^\circ$
2. $\cos90^\circ$
3. $\tan90^\circ$
4. $\tan45^\circ$

Answer: 3
Topic: core-notes
Difficulty: easy
Source: NCERT Section 8.3 aligned
Explanation: $\tan90^\circ=\sin90^\circ/\cos90^\circ$ has a zero denominator.

## 5. Pythagorean identity

Which identity is correct?

1. $\sin^2A-\cos^2A=1$
2. $\sin^2A+\cos^2A=1$
3. $\tan^2A+\cot^2A=1$
4. $\sec^2A+\tan^2A=1$

Answer: 2
Topic: core-notes
Difficulty: easy
Source: NCERT Section 8.4 aligned
Explanation: It follows by dividing the right-triangle Pythagoras relation by the square of the hypotenuse.

## 6. Finding ratios

If $\tan A=3/4$ for an acute angle $A$, then $\sin A$ is:

1. $3/5$
2. $4/5$
3. $3/4$
4. $4/3$

Answer: 1
Topic: ncert-exercises-and-revision
Difficulty: medium
Source: NCERT Exercise 8.1 aligned
Explanation: A right triangle with legs $3,4$ has hypotenuse $5$, so sine is $3/5$.

## 7. Complementary angles

$\sin(90^\circ-A)$ equals:

1. $\sin A$
2. $\cos A$
3. $\tan A$
4. $\sec A$

Answer: 2
Topic: core-notes
Difficulty: easy
Source: NCERT Section 8.2 aligned
Explanation: Opposite and adjacent sides exchange roles for complementary acute angles.

## 8. Proving an identity

When proving a trigonometric identity, the safest method is usually to:

1. change both sides at once
2. start from the more complicated side and simplify it
3. substitute one convenient angle only
4. assume the required equality

Answer: 2
Topic: ncert-exercises-and-revision
Difficulty: medium
Source: NCERT Exercise 8.3 aligned
Explanation: A proof needs algebraic simplification valid for the allowed angles, not a check at one value.
