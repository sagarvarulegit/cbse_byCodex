# Functional groups and naming

A functional group is the reactive part of an organic compound. It gives the compound its characteristic properties.

This is the naming lesson, but naming is not just memorising words. A name tells three things: how many carbon atoms are present, what type of carbon-carbon bond is present, and which functional group controls the compound's reactions.

## Activity 4.2: Alcohol homologous series

The textbook asks students to compare alcohols such as methanol, ethanol, propanol, and butanol.

Notice the pattern:

| Alcohol | Formula |
| --- | --- |
| Methanol | `CH3OH` |
| Ethanol | `C2H5OH` |
| Propanol | `C3H7OH` |
| Butanol | `C4H9OH` |

Each next member differs by `CH2`, but all have the same functional group, `-OH`.

This is why they form a homologous series.

## Learning goals

By the end of this lesson, you should be able to:
- identify common functional groups

## Functional group

A functional group is an atom or group of atoms that decides the chemical properties of an organic compound.

In many carbon compounds, one or more hydrogen atoms of a hydrocarbon chain are replaced by atoms such as chlorine, bromine, oxygen, or nitrogen. The textbook calls these hetero atoms. When the replacing atom or group gives the compound a special set of reactions, we call it a functional group.

Example:
Ethane `C2H6` is a hydrocarbon. If one hydrogen is replaced by `-OH`, the compound becomes ethanol `C2H5OH`. The `-OH` group makes it an alcohol and changes its properties.

Important Class 10 functional groups:

| Functional group | Name |
| --- | --- |
| `-Cl`, `-Br` | halo group |
| `-OH` | alcohol |
| `-CHO` | aldehyde |
| `>C=O` | ketone |
| `-COOH` | carboxylic acid |

The textbook calls atoms such as chlorine, bromine, oxygen, and nitrogen "hetero atoms" when they replace hydrogen in a carbon chain.

Read the table like this:
- halo compounds use prefixes such as chloro- and bromo-
- alcohols use the suffix `-ol`
- aldehydes use the suffix `-al`
- ketones use the suffix `-one`
- carboxylic acids use the suffix `-oic acid`

## Root names

The root name tells the number of carbon atoms in the longest chain.

| Carbon atoms | Root |
| --- | --- |
| 1 | meth- |
| 2 | eth- |
| 3 | prop- |
| 4 | but- |

This is the first part of the name. If you cannot count the carbon chain, the rest of the name will also go wrong.

## Bond suffixes

The bond suffix tells whether the compound has single, double, or triple bonds.

| Bond type | Suffix |
| --- | --- |
| single | -ane |
| double | -ene |
| triple | -yne |

Examples:
- `CH4` is methane
- `C2H6` is ethane
- `C2H4` is ethene
- `C2H2` is ethyne

The ending changes because the bond changes:
- `ethane`: two carbons, single bond
- `ethene`: two carbons, double bond
- `ethyne`: two carbons, triple bond

## Naming with functional groups

When a functional group is present, the name changes to show that group.

Examples:
- `CH3OH` is methanol
- `C2H5OH` is ethanol
- `CH3COOH` is ethanoic acid

For halo compounds, use prefixes such as chloro- or bromo-.

Example:
`CH3Cl` is chloromethane.

## Naming method from the textbook

Use this order:

1. Identify the number of carbon atoms in the longest chain.
2. Choose the root name: meth-, eth-, prop-, or but-.
3. Check if the carbon chain has single, double, or triple bonds.
4. Check if a functional group is present.
5. Add the functional group as a prefix or suffix.

If a suffix begins with a vowel, the final `e` of the carbon-chain name is usually removed.

Example:
`propane` + `one` becomes `propanone`, not `propaneone`.

## Worked naming walk-throughs

`CH3-CH2-Br`

1. Two carbon atoms: root `eth-`.
2. Single bonds: base name `ethane`.
3. Bromine is present as a halo substituent.
4. Name: bromoethane.

`CH3-CH2-OH`

1. Two carbon atoms: root `eth-`.
2. Single bonds: base name `ethane`.
3. Alcohol group `-OH` changes suffix to `-ol`.
4. Name: ethanol.

`CH3-COOH`

1. Two carbon atoms: root `eth-`.
2. Carboxylic acid group is present.
3. Name: ethanoic acid.

## Structural isomers

Structural isomers have:
- the same molecular formula
- different structural arrangements

Example:
`C4H10` can be arranged as a straight chain or as a branched chain.

This is possible because carbon can form chains and branches.

Structural isomers are important because formula alone is not always enough. Two compounds can have the same molecular formula but different connections between atoms. Different structure can mean different properties.

For bromopentane, structural isomers are possible because bromine can be attached at different positions on the five-carbon chain.

## Solved examples

### Example 1: Functional group

Question:
Identify the functional group in ethanol, `C2H5OH`.

Answer:
The functional group is `-OH`, so ethanol is an alcohol.

### Example 2: Naming

Question:
Name `C3H8`.

Answer:
It has three carbon atoms, so root is prop-. It has single bonds, so suffix is -ane. The name is propane.

### Example 3: Carboxylic acid

Question:
Which functional group is present in `CH3COOH`?

Answer:
`-COOH`, the carboxylic acid group.

### Example 4: Butanone

Question:
Butanone is a four-carbon compound. Which functional group does it contain?

Answer:
The suffix `-one` shows a ketone group, `>C=O`.

### Example 5: Propanone name formation

Question:
Why is a three-carbon ketone called propanone?

Answer:
The three-carbon chain gives propane. The ketone suffix is `-one`. Since `one` begins with a vowel sound, the final `e` in propane is removed: propane - e + one = propanone.

### Example 6: Bromoethane

Question:
Name `CH3-CH2-Br`.

Answer:
It has two carbon atoms, so the root is eth-. Bromine is a halo group used as a prefix. The name is bromoethane.

## Common mistakes

1. Calling `-OH` a carboxylic acid group.
2. Forgetting the root names meth-, eth-, prop-, and but-.
3. Mixing up ethane and ethanol.
4. Thinking compounds with the same formula must always have the same structure.

## Board tips

- First count carbon atoms, then check bond type, then look for functional group.
- In naming answers, write the full name clearly: ethanol, ethanoic acid, propane.
- Learn the table of functional groups; it is a high-value revision table.
